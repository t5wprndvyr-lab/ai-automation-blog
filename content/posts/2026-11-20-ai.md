## 3. 自動化の実践例：メールの整理
正直に言って、メールの整理は面倒な作業。そこで、Claude Codeを使うことで、メールの整理を自動化します。具体的なコード例は以下です：
```python
import os
import shutil
def organize_emails():
    # メールのフォルダを整理する
    src_folder = "/path/to/email/folder"
    dst_folder = "/path/to/organized/folder"
    # フォルダの存在確認
    if not os.path.exists(dst_folder):
        os.makedirs(dst_folder)
    # ファイル一覧取得
    files = os.listdir(src_folder)
    for file in files:
        # 一定の条件に当てはまるファイルを移動
        if "未読" in file:
            shutil.move(os.path.join(src_folder, file), os.path.join(dst_folder, file))
```
正直に言って、このコードは基本的な例ですが、実用性が高い。
