## はじめに
今やAIは個人開発者にとって欠かせないツールの一つとなっています。しかし、会社員の副業においては、定時で帰って、自動化で稼ぐことが重要です。本記事では、Macを使ったAI開発環境の構築方法と、Claude CodeとCodexの使い分けについて詳しく解説します。同じ会社員の副業者として、実際の体験から学んだことや注意点を共有します。
## MacでのAI開発環境構築
### 1. 必要なソフトウェアのインストール
AI開発に必要なソフトウェアをインストールしましょう。まずは、Pythonとその開発環境であるPyCharmをインストールします。PyCharmはPython開発に特化したIDEで、コードの自動完成やエラー検出機能が豊富です。
```bash
brew install pyenv
pyenv install 3.9.6
pyenv global 3.9.6
pip install pycharm
```

AIプロジェクトをGitHubにプッシュする前に、GitHubのアカウント設定を行いましょう。GitHubでのプロジェクト管理は重要なステップです。
