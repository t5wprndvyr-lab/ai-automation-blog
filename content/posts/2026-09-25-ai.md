## 自動化の具体的な事例
例えば、毎日同じスクリプトを書く作業は自動化できる。まずはPython標準ライブラリやbashコマンドを使って、定期的なタスクを自動化する方法を考える。例えば、メールの受信とメール内の特定キーワード検索を自動化すれば、時間節約になる。
```python
import os
import smtplib
from email.message import EmailMessage
def check_email():
    # メールサーバに接続
    with smtplib.SMTP('smtp.example.com', 587) as smtp:
        smtp.starttls()
        smtp.login('user@example.com', 'password')
        # メール受信
        resp, data = smtp.list()
        emails = data.decode('utf-8')
        email_list = emails.split('\n')
        for email in email_list:
            if 'keyword' in email:
                # メール詳細取得
                resp, data = smtp.retr(email.split()[2])
                msg_data = data.decode('utf-8')
                msg = EmailMessage()
                msg.set_payload(msg_data)
                # メール内の特定キーワード検索
                if 'search_word' in msg.get_payload():
                    print('キーワード検索結果:', msg.get_payload())
check_email()
```
