## はじめに
私は会社員ですが、平日夜と週末を使ってAI自動化に取り組んでいます。ここでは、AI自動化を副業としてどのように活用するか、そしてその際の注意点について語ります。
## AI自動化の始まり
最初は、毎日同じ作業を重複するのではなく、それが機械に任せることで解放される時間を考えました。具体的には、メールの自動整理やデータの自動入力、レポート作成の自動化などです。
### クラウドCodeとCodexの使い分け
### クラウドCodeとCodexの使い分け
Claude CodeとCodexは、それぞれ異なる目的で使うツールです。Claude Codeは自然言語処理を強化したAIで、Codexはコード生成に特化しています。例えば、メールの自動整理ではClaude Codeを利用し、データの分析やコードの生成ではCodexを使うのが効果的です。
## 実践的な例
### メールの自動整理
まず、Claude Codeを使ってメールの自動整理を試みました。具体的には、特定のキーワードが含まれているメールを一括で移動するように設定しました。
```bash
python -c "import imaplib, email; imaplib.IMAP4_SSL('imap.example.com').select().search(None, 'TEXT \"特定キーワード\"')"
```
### データの自動入力
次に、Codexを使ってデータの自動入力を行いました。例えば、Excelシートの特定の列にデータを自動的に入力する機能を実装しました。
```python
import openpyxl
workbook = openpyxl.load_workbook('データ.xlsx')
sheet = workbook.active
for row in range(2, sheet.max_row + 1):
    sheet[f'B{row}'] = f"自動入力{row}"
workbook.save('データ.xlsx')
```
