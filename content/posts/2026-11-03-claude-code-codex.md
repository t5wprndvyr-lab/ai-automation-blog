## はじめに
平日夜と週末の空き時間を使って副業でAI自動化に取り組んでいる会社員の私です。正直に言うと、定時で帰って、自動化で稼ぐことは日々の目標としています。
## Claude CodeとCodexの違い
まず、Claude CodeとCodexの違いを明確にしておきましょう。Claude CodeはAnthropic社が開発したAIコーディングツールで、CodexはOpenAIが開発したもので、別々の会社の別々の製品です。
Claude Codeは自然言語処理能力が高く、コードを生成する際の指示が比較的自然言語で可能になります。一方、Codexはプログラミング言語の文法を理解し、具体的なコードを生成する能力が強いです。
## プロンプト設計のコツ
AIツールを上手に活用するためには、効果的なプロンプト設計が重要です。プロンプト設計のコツは以下の通りです。
1. **明確に指示を伝える**: 「何を作成するのか」や「どのような動作をするのか」を明確に伝える必要があります。曖昧な指示はAIにも理解させにくくなります。
2. **詳細な指示を与える**: 例えば、プログラムの目的や入力、出力の形式など具体的に指示を出します。これによりAIはより正確なコードを生成します。
3. **検証可能な例を提供する**: プロンプトに具体的な検証例を含めると、生成されたコードの品質を判断しやすくなります。
4. **適切なフレーズを使用する**: 例えば、「Pythonで実装」や「関数を定義してください」など、AIが理解しやすいフレーズを使用します。
## Claude CodeとCodexの使い分け
Claude CodeとCodexを効果的に使い分けるためには、それぞれの特性を理解することが重要です。
- **Claude Code**: 比較的自然言語的な指示でコードを生成することができます。ただし、具体的なコード構造の指示が必要な場合はCodexの方が適しているかもしれません。
- **Codex**: シンプルなプログラミング言語の文法を理解し、具体的なコードを生成することができます。ただし、自然言語の指示に対応できるClaude Codeとの連携は必須です。
## 実践例
以下に具体的な例を示します。
### 例1: Claude Codeを使用
プロンプト: 「Pythonでリストの要素を並べ替え、偶数番目の要素のみを抽出する関数を作成してください。」  
生成されたコード: ```python
def extract_even_indexed_elements(lst):
    return [lst[i] for i in range(0, len(lst), 2)]
```
### 例2: Codexを使用
プロンプト: ```python
def sum_even_indexed_elements(lst):
    # Your code here
```
生成されたコード: ```python
def sum_even_indexed_elements(lst):
    return sum(lst[i] for i in range(0, len(lst), 2))
```
