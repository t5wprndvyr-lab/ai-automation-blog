## 1. GitHub (最優先・他の全ての土台)

- サインアップ: https://github.com/signup (アカウント未作成の場合のみ)
- ログイン済みなら不要。ターミナルで以下を実行するだけです。

```bash
export PATH="$HOME/bin:$PATH"
gh auth login --web -h github.com -p https
```

ログインが終わったら教えてください。リポジトリ作成・push・GitHub Pages設定まで自動で行います。

承認後、`API Key / API Secret / Access Token / Access Token Secret` を発行し、
このプロジェクトの `.env` の `X_API_KEY` などに**ご自身で**貼り付けてください。

## 3. Google AdSense — サイトの広告収益化

申請先: https://www.google.com/adsense/start/

- サイトURL: `https://<あなたのGitHubユーザー名>.github.io/ai-automation-blog/` (Pages設定完了後に判明)
- カテゴリ: `コンピュータ・電子機器` または `テクノロジー`
- 支払い先の氏名・住所・銀行情報の入力はご自身で行ってください(私は代行できません)
- 審査には記事が数本(目安10本前後)たまってから申請するのがおすすめです

承認後発行される `ca-pub-XXXXXXXXXXXX` を `.env` の `ADSENSE_CLIENT_ID` に設定 → `python3 scripts/build_site.py` を再実行すれば全記事に自動反映されます。
