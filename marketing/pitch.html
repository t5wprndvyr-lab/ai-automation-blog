Available for work

AIで、御社の定型業務を無人化します。

Claude Code / Codex を使い、記事作成・データ整形・SNS告知・レポート作成などの繰り返し作業を、 毎日自動で回るパイプラインに組み替えます。実際に自分で運用している自動化基盤を、そのまま実績としてお見せします。

# 実際に稼働中の自動化パイプライン(抜粋)
$ python3 scripts/generate_post.py # Claude APIで記事生成
生成完了: content/posts/2026-09-13-....md
$ python3 scripts/build_site.py # 静的サイトへビルド
ビルド完了: 12件の記事 -> docs/
$ git push && python3 scripts/post_to_x.py
投稿完了 # 公式APIでXに告知

できること

01

コンテンツ自動生成 → 公開

ブログ記事・商品説明・レポートをAIで生成し、静的サイトやCMSへ自動公開するパイプラインを構築します。

02

定型業務の自動化

Excel/PDF/メールの集計・転記・返信文面作成など、手作業のルーティンをスクリプト化します。

03

公式APIでの告知連携

X等への自動告知は必ず公式APIの範囲内で実装し、アカウント凍結のリスクを避けます。

04
