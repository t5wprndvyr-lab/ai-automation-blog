MacでのAI開発環境構築

2026-09-19

はじめに

平日は定時後の2時間しか触れないので、週末と夜遅くにAI自動化に取り組んでいます。この記事ではMac向けのAI開発環境の構築方法を説明します。

Macの準備

まず、Macの準備から。公式サイトの案内に従ってインストールしてください。Pythonとgitは必須ですので、それらを最新版にアップデートします。その後、Homebrewというパッケージマネージャーをインストールしましょう。/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" というコマンドを実行することでインストールできます。ただし、実在しないURLを使うのを避けるため、公式サイトに従ってください。

Pythonと必要なライブラリ

Pythonの環境を整えるために、pip をアップデートします。pip install --upgrade pip でアップデートします。次に、AI開発で頻繁に使うライブラリをインストールします。pip install numpy pandas scikit-learn などです。これらはClaude CodeやCodexを使う上で必要なライブラリです。

Claude CodeとCodexの使い分け

結論から言うと、Claude CodeはAPIベースのツールで、特定のタスクに対してプロンプトを入力することで結果を得ることができます。一方、Codexはコード生成ツールで、自然言語の指示に基づいてコードを生成します。正直に言うと、Claude Codeは具体的な問題解決に向いている一方、Codexは抽象的なコード生成に向いていると言えるでしょう。

実際の使い方

例えば、クラウドサービスのデータ分析を行う場合、Claude Codeは具体的なAPI操作をプロンプトで指定できます。一方、Codexはより抽象的な指示で複雑なデータ処理のコードを生成できます。そのため、具体的なタスクにはClaude Code、抽象的なタスクにはCodexを使うのが良いでしょう。
