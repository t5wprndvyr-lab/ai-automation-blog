はじめに

AI自動化とは、作業を自動化することで効率化を図る技術です。会社員が副業で取り組むなら、平日は定時後の2時間しか触れないので、週末の自由時間を活用するのがおすすめです。正直に言うと、まずはClaude CodeとCodexの違いを理解することが重要です。

Claude CodeとCodexの使い分け

Claude Code

Claude Codeは Anthropic 社が開発したAIコーディングツールです。その特徴は、自然言語による指示でコードを生成できる点です。ただし、Claude Codeはまだ実用化段階にあり、一部の機能に制限があります。例えば、特定のライブラリのサポートが不完全な場合もあります。

Codex

Codexは OpenAI が開発したAIコーディングツールです。こちらはClaude Codeよりも機能が充実しており、多くのライブラリのサポートが可能です。ただし、プライバシーへの配慮から、一部の指示に対しては応答しないことがあります。

使い分け

Claude CodeとCodexの使い分けは、具体的なプロジェクトによって変わります。例えば、プライバシーに気を使う必要がないプロジェクトならCodexが適していますが、プライバシーが気になるプロジェクトならClaude Codeを検討します。

具体的な手順

1. プロンプト設計のコツ

Claude CodeやCodexを効果的に利用するためには、明確な指示を伝えるプロンプトが必要です。具体的な指示を細かく設定することで、AIが正しく理解し、期待通りの結果を出力します。

2. サンプルコードと実用的な例

例1: ファイルのバックアップ自動化

# ファイルのバックアップを自動化
#!/bin/bash
date=$(date +%Y%m%d)
tar -czvf backup_$date.tar.gz /path/to/important/files

例2: 電子メールの自動送信

import smtplib
from email.mime.text import MIMEText
def send_email(subject, body, to_addr):
    msg = MIMEText(body)
    msg['Subject'] = subject
    msg['From'] = 'your_email@example.com'
    msg['To'] = to_addr
    with smtplib.SMTP('smtp.example.com', 587) as smtp:
        smtp.starttls()
        smtp.login('your_email@example.com', 'your_password')
        smtp.sendmail('your_email@example.com', to_addr, msg.as_string())
# 送信例
send_email('Important Update', 'Check the attached document.', 'recipient@example.com')

3. チェックリスト

  • プロンプトは明確で具体的であること
  • 必要なライブラリは事前にインストールすること
  • プロプライエタリーな情報は適切に管理すること
