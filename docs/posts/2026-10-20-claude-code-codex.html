はじめに

この記事では、AI自動化に取り組む個人開発者やフリーランスエンジニア向けに、プロンプト設計のコツと、AnthropicのClaude CodeとOpenAIのCodexの使い分けについて詳しく解説します。副業としての視点から、実際の体験から得た知見を交えて語りましょう。

プロンプト設計のコツ

AI自動化の第一歩はプロンプト設計です。適切なプロンプトはAIが意図した通りの結果を生成するための鍵です。以下に、プロンプト設計のコツをいくつか紹介します。

明確な目標設定

明確な目標を設定することは極めて重要です。例えば、自動化したいタスクが「データ分析」であれば、「特定のCSVファイルから売上データを分析し、月別の売上合計を表示するPythonスクリプトを作成してください」という明確なプロンプトが求められます。

プロンプトの具体性

具体的な指示はAIに正確な動作を期待させます。例えば、「売上データは2022年1月から2023年12月までのもの」と具体的な期間を指定することで、AIが期待通りの結果を生成します。

複数のプロンプトを用意する

一つのプロンプトではAIが理解できなかった場合、別の角度から再度プロンプトを試すことも有効です。例えば、初期プロンプトが「月別売上を表示」という場合、次のプロンプトで「各月の売上合計を計算し、グラフで表示」などと具体的に指定します。

Claude Code と Codex の使い分け

Claude Code の特徴

Claude CodeはAnthropicが提供するAIコーディングツールです。以下に、Claude Codeの特徴とその使い方を解説します。

実用的な成果提供

Claude Codeは、コードの生成だけでなく、具体的な実行結果を提供します。例えば、以下のプロンプトでClaude Codeを試してみましょう：

特定のCSVファイルから売上データを分析し、月別の売上合計を表示するPythonスクリプトを作成してください。売上データは2022年1月から2023年12月までのもので、結果はコンソールに出力してください。

Claude Codeは生成したコードの実行結果を表示します。その結果が意図したものであれば、そのコードをそのまま使用することができます。

範囲内での利用

会社にバレない範囲で、定時で帰って自動化で稼ぐために、Claude Codeは非常に有用です。定時以降の2時間でプロンプトを入力し、生成されたコードを確認・修正して利用します。

Codex の特徴

CodexはOpenAIが提供するAIコーディングツールです。以下に、Codexの特徴とその使い方を解説します。

総合的な提案

Codexはコードの生成だけでなく、複数の代替案を提案します。例えば、以下のプロンプトでCodexを試してみましょう：

特定のCSVファイルから売上データを分析し、月別の売上合計を表示するPythonスクリプトを作成してください。売上データは2022年1月から2023年12月までのもので、結果はコンソールに出力してください。

Codexは複数のコード提案を表示します。その中から最も適切なものを選択して修正することで、自分好みのコードを生成できます。

オープンソースコミュニティのサポート

CodexはOpenAIのコミュニティに参加することで、より具体的な提案を得られます。例えば、Stack OverflowやGitHubのようなオープンソースコミュニティに参加し、問題を共有することで、より具体的なコード提案を得ることができます。

まとめ

結論から言うと、Claude CodeとCodexの使い分けは具体的な目的や使用状況によって決まります。Claude Codeは実行結果をすぐに確認でき、Codexは複数の提案から選択できるという利点があります。副業としてAI自動化を行う上で、自分に合ったツールを選択して活用しましょう。 定時で帰って、自動化で稼ぐ。
