Mac向けAI開発環境の準備

1. ソフトウェアのインストール

まず、PythonとAnacondaをインストールしましょう。これらはAI開発で頻繁に使用するツールです。

$ brew install python
$ brew install anaconda

2. エディタの選択

VSCodeはAI開発に最適なエディタの一つです。以下のようにインストールします。

$ brew install --cask visual-studio-code

3. プロンプトエンジンの設定

Claude CodeとCodexはAIコーディングツールですが、使い分ける必要があります。Claude Codeを使うなら以下のように設定します。

$ conda install -c conda-forge openai

Codexを使うなら、以下の手順でインストールします。

$ conda install -c conda-forge openai

4. パッケージのインストール

必要に応じて以下のパッケージをインストールします。

$ pip install numpy pandas scikit-learn
